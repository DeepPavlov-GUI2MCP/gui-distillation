**Фаза:** 0.1 Domain Specification  
**Дата:** 2026-02-17  
**Исполнитель:** RT  
**Целевое приложение:** GNOME Calculator (версия: 3.38.0+)  

---

## 1. Выбор целевого приложения

### 1.1. Обоснование выбора GNOME Calculator

| **Простота автоматизации**         | Регулярная сетка кнопок, предсказуемое поведение, отсутствие анимаций |  
| **Визуально различимые элементы**  | Кнопки с цифрами, операциями, дисплей — все четко выделены            |  
| **Разнообразие действий**          | 15+ различных кнопок (цифры, операции, специальные функции)           |  
| **Детерминированность**            | Одно и то же действие всегда дает одинаковый результат                |  
| **Размер пространства состояний**  | Дисплей может показывать любые числа, но структура UI фиксирована     |  
| **Наличие логики**                 | Есть семантика (числа, операции, ошибки), но не слишком сложная       |  
| **Воспроизводимость**              | Стандартное приложение GNOME, легко установить в любой Ubuntu         |  

### 1.2. Альтернативы (рассмотренные, но отклоненные)

| GNOME Mines (Сапёр) | Случайность первого хода, меньше типов действий (только клик/флаг) |  
| VLC                 | Сложнее в автоматизации (меню, списки воспроизведения)             |  
| GIMP                | Слишком сложен (много окон, модальные диалоги)                     |  
| Текстовый редактор  | Работа с текстовым полем требует позиционирования курсора          |  

### 1.3. Версия приложения

**Название:** GNOME Calculator  
**Версия:** 3.38.0+  
**Пакет:** gnome-calculator  
**Источник:** официальный репозиторий Ubuntu (apt)

## 2. Операционная система и окружение

### 2.1. Базовая система

**Хост:** Manjaro Linux (рабочая станция)  
**Виртуализация:** QEMU/KVM  
**Гостевая ОС:** Ubuntu 22.04 LTS (Jammy Jellyfish)  

### 2.2. Графическое окружение

**Сервер отображения:** X11 (X.Org)  
**Виртуальный дисплей:** Xvfb (X virtual framebuffer)  
**Разрешение:** 1280x1024, 24-bit color  
**Обоснование:** pyautogui требует X11 для работы. Wayland не поддерживается. Xvfb позволяет запускать приложение "вглухую" без физического дисплея, что обеспечивает воспроизводимость  

### 2.3. Инструменты автоматизации

Язык: Python 3.10+  
Библиотеки:  
- pyautogui (эмуляция мыши/клавиатуры)  
- Pillow (работа со скриншотами)  
- OpenCV (опционально, для поиска элементов)  
- python-xlib (низкоуровневый доступ к X11)

## 3. UI-паттерны приложения

### 3.1. Структура интерфейса

- дисплей  
- функциональные кнопки  
- цифры и операции  
- память  


### 3.2. Типы элементов

| **Цифровые кнопки**       | 0-9        | Квадратные, содержат цифру           |  
| **Кнопки операций**       | +, -, ×, ÷ | Круглые или цветные, символ операции |  
| **Функциональные кнопки** | C, CE, =   | Другой цвет, особое положение        |  
| **Дисплей**               | -          | Верхняя панель, моноширинный текст   |  
| **Кнопки памяти**         | M+, M-, MR | Редко используются, дополнительные   |  

### 3.3. Состояния приложения

| **Ожидание ввода**   | Дисплей показывает 0            | Только что открыли     |  
| **Ввод числа**       | На дисплее набираемое число     | Нажали "1", "2" → "12" |  
| **Операция введена** | Дисплей показывает первое число | Нажали "2", "+"        |  
| **Результат**        | Дисплей показывает результат    | Нажали "="             |  
| **Ошибка**           | Дисплей показывает "Error"      | Деление на ноль        |

## 4. Границы применимости (Boundaries)

### 4.1. Что ВХОДИТ в область исследования

**Поддерживается:**  
- Базовый режим калькулятора (Basic)  
- Все цифровые кнопки (0-9)  
- Базовые операции (+, -, ×, ÷)  
- Функциональные кнопки (C, CE, =, +/-, .)  
- Детерминированные последовательности действий  

### 4.2. Что НЕ входит (исключено на данном этапе)

**Не поддерживается (будущие фазы):**  
- Инженерный режим (Advanced) с тригонометрическими функциями  
- Кнопки памяти (M+, M-, MR, MC)  
- Клавиатурные сокращения  
- Изменение размера окна  
- Темы оформления  
- Анимации и переходы  

### 4.3. Допущения (Assumptions)

1. **Приложение всегда запускается в чистом состоянии** (дисплей = 0)  
2. **Все элементы видимы** (не нужно скроллить или открывать меню)  
3. **Нет всплывающих окон** (калькулятор модальный)  
4. **Цвета и позиции кнопок фиксированы** (стандартная тема)  
5. **Скриншоты делаются с задержкой** после действий (интерфейс успевает обновиться)  
6. **Мышь всегда в стандартном состоянии** (нет "залипания" кнопок)  

### 4.4. Ограничения (Limitations)

1. **Координатная привязка:** Начальные тесты используют абсолютные координаты (позже заменится на компьютерное зрение)  
2. **Разрешение экрана:** Фиксировано 1280x1024 (в Xvfb)  
3. **Скорость:** Между действиями вставлены паузы (0.5-1 сек) для стабильности  
4. **Только мышь:** Клавиатура не используется (даже если калькулятор поддерживает)
